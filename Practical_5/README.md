## 📌 Aim & Objective
Implement higher-order array methods (`map`, `filter`, `reduce`, `push`) to process shopping cart operations, calculate subtotal, line-item taxes (GST), and total order prices in an interactive luxury boutique storefront.

---

## 💡 Key JavaScript Concepts Demonstrated
* **Array Insertion (`push`, `unshift`):**
  * Dynamically appending custom or selected products into the shopping cart state.
* **Array Mapping (`map`):**
  * Transforming an array of cart item objects into line-item prices (`price * quantity`).
* **Array Filtering (`filter`):**
  * Removing items from the shopping bag by filtering out items matching target product IDs.
* **Array Reduction (`reduce`):**
  * Aggregating total item count, cumulative subtotal, 18% GST tax calculation, and order total.

---

## 🚀 Key Features
* Luxury editorial high-fashion storefront design.
* Interactive product catalog with image hover zoom and "Add to Bag" actions.
* Real-time slide-over shopping bag drawer with physical boutique receipt typography and barcode.
* Quantity modifiers (+ / -) with instant array pipeline recalculation.
