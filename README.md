## 🚀 How to Run the Web Projects

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/Yashkhadgi/JavaScript-Lab.git
   cd JavaScript-Lab
   ```
2. **Open in VS Code**:
   ```bash
   code .
   ```
3. **Launch Any Practical / Task**:
   * Open any project folder (e.g. `Practical_11/index.html` or `Task_2/index.html`).
   * Right-click `index.html` and click **"Open with Live Server"** (recommended for ES6 modules and Fetch API).
