## 📌 Repository Overview

This repository contains the complete set of **JavaScript Laboratory Experiments (Practicals 1 to 10)** and supplementary practical tasks assigned as part of the college web development curriculum.

Each practical is designed as a standalone, responsive, single-viewport web application implementing specific core concepts of modern JavaScript (ES6+), DOM manipulation, Web Storage, and Asynchronous APIs.

## 🚀 How to Run Practicals Locally

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/Yashkhadgi/JavaScript-Lab.git
   cd JavaScript-Lab
   ```
2. **Open in VS Code**:
   ```bash
   code .
   ```
3. **Run Any Practical**:
   - Open any experiment folder (e.g. `Practical_5/index.html` or `Task_2/index.html`).
   - Right-click `index.html` and select **"Open with Live Server"** (or double-click `index.html` to open in your web browser).
