# JavaScript Lab Practicals

A collection of 10 standalone web applications demonstrating core to advanced JavaScript concepts, UI design paradigms (Neumorphism, Cyberpunk, Glassmorphism, Brutalism, Flat, 3D), and responsive web development standards.

---

## 📌 Practicals Index & Topics

| Practical | Topic & Focus | Design Paradigm | Key Technologies |
|---|---|---|---|
| **Practical 1** | Inline, Internal & External JS | Modern Hero Dashboard | DOM events, script placement, functions |
| **Practical 2** | `var`, `let`, `const` Scope | Smart Billing Calculator | Variable scope, template literals, destructuring |
| **Practical 3** | Functions & Objects | Neumorphism (Soft UI) | Radial SVG ring, Pass/Fail rubber stamp animation |
| **Practical 4** | Strings & Control Flow | Cyberpunk Neon Terminal | 3D vector character bridges, string symmetry analytics |
| **Practical 5** | Array Pipeline & Methods | Skeuomorphic E-Commerce | Jagged barcode receipt, `.push()`, `.map()`, `.reduce()` telemetry |
| **Practical 6** | Regular Expressions | Dark Glassmorphism | `backdrop-filter: blur(16px)`, laser beam scanner, word length chart |
| **Practical 7** | DOM Tree Traversal | Minimalist Notion-Style | Category sidebar, live DOM Tree Traversal path monitor |
| **Practical 8** | Event Validations & Forms | Athletic Volt 3D | Cursor-tracked 3D tilt member ID badge, plan perks checklist |
| **Practical 9** | Web Storage APIs | Apple-Style Clean Flat | `localStorage` theme & `sessionStorage` font scale, raw inspector |
| **Practical 10** | Async Fetch API & jQuery | Brutalist Tech Dashboard | Native `fetch()` vs. `$.getJSON()`, latency meter, syntax logger |
