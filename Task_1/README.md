## 📌 Aim & Objective
Implement client-side authentication form validation, real-time input status indicators, password strength evaluation, and session state transitions using modern JavaScript and DOM manipulation.

---

## 💡 Key JavaScript Concepts Demonstrated
* **Real-Time Input Validation Listeners:**
  * Monitoring `input` events on email and password fields.
  * Email format verification via regular expressions.
* **Password Strength Meter Engine:**
  * Scoring passwords based on length, uppercase characters, digits, and special symbols.
  * Real-time progress bar color feedback (Weak: Red, Moderate: Amber, Strong: Green).
* **DOM State Switching:**
  * Toggling between Login, Registration, and Authenticated User Session views dynamically without page reloads.
* **Notification System:**
  * Animated toast banner feedback on successful authentication or input errors.

* Scandinavian security panel design with frosted glass card styling.
