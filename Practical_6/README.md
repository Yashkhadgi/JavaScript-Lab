## 📌 Aim & Objective
Implement JavaScript Regular Expressions (`RegExp`, `test()`, `match()`, `replace()`) to build an interactive developer matrix console that extracts emails, phone numbers, URLs, and evaluates custom regex patterns in real time.

---

## 💡 Key JavaScript Concepts Demonstrated
* **Pattern Testing (`regex.test(string)`):**
  * Instant boolean verification of email formats, phone numbers, and URL structures.
* **Global Pattern Extraction (`string.match(regex)`):**
  * Extracting multiple occurrences of target patterns into arrays.
* **Regex Flag Modifiers:**
  * Utilizing global (`g`), case-insensitive (`i`), and multiline (`m`) flags.
* **Text Analytics:**
  * Word count, line numbers, character distribution, and execution benchmarking.

---

## 🚀 Key Features
* Dark developer studio / threat scanner interface layout.
* Mined entities rendered as interactive glowing chips.
* Live regex tester with instant match group highlighting.
* Pre-configured patterns: Emails, Phone numbers (Indian/International), Hex colors, and Dates.
