## 📌 Aim & Objective
Demonstrate the fundamental ways of integrating JavaScript into web documents (Inline, Internal `<script>`, and External `.js` files) and implement dynamic real-time string length analysis with character counting.

---

## 💡 Key JavaScript Concepts Demonstrated
* **JavaScript Integration Methods:**
  * **Inline:** Direct event attributes (e.g., `onclick="handleClick()"`).
  * **Internal:** Embedding `<script>` tags within the HTML document `<head>` or `<body>`.
  * **External:** Linking modular `.js` files via `<script src="script.js">` for clean separation of concerns.
* **DOM Event Listeners:** Real-time `input` event tracking on text areas.
* **String Properties & Methods:** Computing `.length`, space trimming (`trim()`), word breakdown (`split(/\s+/)`), and live character limit evaluation.

---

## 🚀 Key Features
* Clean, minimalist responsive user interface.
* Real-time metrics: character count, character count excluding spaces, word count, and reading time estimation.
* Clear button to purge input and reset telemetry counters.
